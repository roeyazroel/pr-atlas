Read the security boundaries ↗
  • 01Local-first by defaultSource, inputs, logs, and validated walkthroughs stay in Electron app data; managed worktrees do not alter your checkout.
  • 02Explicit provider consentSee the provider-specific confirmation before repository context is sent to its configured model service.
  • 03Fixed, validated UISchema-checked JSON renders in the app. Provider-generated HTML and JavaScript never execute in the renderer.
  • 04Read-oriented GitHub accessDiscovery fetches and reads. PR Atlas does not post, edit, resolve, or approve reviews.
